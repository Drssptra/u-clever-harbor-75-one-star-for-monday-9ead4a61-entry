A program that prints one funny one-star review of Monday, written as if Monday were a restaurant — a single line of plain text, 126 characters, 24 words. It prints the review to stdout and writes the exact same text (no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt` for the sealed scorer.

## Run it

```sh
node main.ts
```
